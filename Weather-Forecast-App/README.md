# Interactive Weather Forecast App

A Python GUI weather application built using Tkinter and OpenWeather API.

## Features

- Real-time weather information
- Temperature display
- Feels-like temperature
- Humidity
- Wind speed
- Weather condition
- Dynamic background colors
- Weather emojis
- Date and time display
- Enter key search support
- Error handling

## Technologies Used

- Python
- Tkinter
- Requests API
- OpenWeather API

## How to Run

Install requests:

```bash
python -m pip install requests
```

Run:

```bash
python weather_app.py
```
